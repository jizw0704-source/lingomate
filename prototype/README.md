# 灵果 · 原型 01

这是可以实际操作的本地浏览器原型。输入拼音后，可以选择中文、英文或展开后的第三种译法，把选中的文字写入页面文本区。

打开 **http://127.0.0.1:9037**。如果服务已经停止，在此目录运行 `pnpm serve`；首次构建的命令见 AGENTS.md。

## 体验方法

1. 默认拼音为 `xuexi`，可以直接点击“学习”“study”或“learn”。
2. 点击“展开更多译法与用法”，查看区别和例句，也可以选择“learning”。
3. 换成 `kaifa` 或 `gongzuo`，分别比较 develop / exploit / development、work / job / operate。
4. 切换“普通中文”，只显示中文；切回“中英候选”继续选择英文。未提交拼音和已输出文本都保留。
5. 文本区可以直接编辑、选择一段文字后替换、撤销上次输出、清空或复制。

请将当前系统键盘切到英文，输入拼音字母。空格选择当前中文候选；Shift＋空格选择该候选第一种英文；上下方向键切换前五个候选；数字 1–5 选择中文；Enter 输出原样拼音；Esc 收起已展开的译法。其他译法可以点击或用 Tab 到对应按钮，再按 Enter。

## 实现范围

- 拼音解析、中文候选、本地常用译词和提交消耗拼音，实际调用本地 Rust 引擎。没有用预先写好的候选画面替代引擎查询。
- 译法详情在独立的 `data/details.json` 中，当前为 30 个常用词编写语境、词性和例句；它们是原型教学示例，没有经过专业词典编辑审校。其他命中的译词显示上游词表原始释义。
- 紧凑候选显示最多两个英文表达，展开可以选择更多；选定的合法译法经引擎的 `commit_translation` 提交。没有修改上游“最多两条释义”的数据结构。
- 页面只展示前五个中文候选，本次不实现翻页。`kaifazhe` 选择“开发”或 develop 后，剩余 `zhe` 由真实引擎保留。
- 服务只监听本机，运行时不请求云翻译、不读取个人输入法配置、不保存输入日志。文本只存在当前页面内存中，刷新会清空。
- 当前页面尚未接入系统输入法，不能直接在微信、邮件等其他应用里输入。手机宽度检查不等于手机真实键盘验证。

## 文件与许可

前端为 TypeScript + Vite，后端为 Python 标准库，`bridge/` 为 Rust 引擎适配器；未增加 JavaScript 生产依赖。运行、格式、静态检查、类型检查、构建和测试命令见 AGENTS.md。测试和设计检查的结果见 QA.md。
