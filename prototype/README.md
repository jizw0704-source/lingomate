# 灵果 · 网页原型

网页原型用于验证中文拼音输入、中英候选选择和多译法交互。用户提交的文字显示在页面文本区；该原型不作为系统输入法使用。

## 运行与操作

首次准备环境及构建的命令见 [开发说明](AGENTS.md)。构建完成后，在本目录执行 `pnpm serve`，访问 <http://127.0.0.1:9037/>。

输入拼音前，将系统键盘切换为英文输入。可使用以下示例检查交互：

1. 输入 `xuexi`，选择“学习”、`study` 或 `learn`。
2. 展开更多译法与用法，查看语境和例句，并选择 `learning`。
3. 输入 `kaifa` 或 `gongzuo`，比较对应译法。
4. 切换“普通中文”与“中英候选”，检查未提交拼音及已输出文本是否保留。
5. 在文本区编辑、替换选区、撤销上次输出、清空或复制文本。

| 操作 | 功能 |
| --- | --- |
| 空格 / 数字 1–5 | 确认中文候选 |
| Shift＋空格 | 确认当前候选的第一种英文译法 |
| ↑ / ↓ | 切换前 5 个候选 |
| Enter | 提交输入框中已规范化的拼音字母 |
| Esc | 收起展开的译法 |
| 点击译法，或 Tab 聚焦后按 Enter | 确认其他译法 |

网页原型会规范化拼音输入；保留大小写的中英混合输入由 macOS 原生版本提供。

## 实现范围

- 中文候选、离线释义及拼音提交由本地 Rust 引擎处理。选用 `kaifazhe` 中的“开发”或 `develop` 后，引擎保留剩余 `zhe`。
- `data/details.json` 包含 30 个常用词的语境、词性和例句。这些内容属于交互验证示例，尚未经过专业词典审校。
- 候选区最多显示两种英文表达，展开后可选择更多；译法经引擎校验后提交。
- 页面仅展示前 5 个中文候选，未接入分页、系统输入或整句翻译。
- 服务仅监听本机地址，不请求在线翻译，不读取个人输入法配置，也不保存输入日志。页面文本保存在内存中，刷新后清空。

## 开发与许可

前端使用 TypeScript 与 Vite，本机服务使用 Python 标准库，`bridge/` 提供 Rust 引擎适配器。格式检查、静态检查、类型检查、测试及构建命令见 [开发说明](AGENTS.md)，已有验证结果见 [QA](QA.md)。
