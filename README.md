## 使用

在输入源中选择“灵果”，输入拼音：

- 单按并松开Shift，在中文拼音 / 英文直输之间切换；英文直输时字母原样输出。
- 中文模式下回车输出当前原样字母并保留大小写；随后继续中文输入。没有待确认字母时，回车仍由原应用换行或发送。
- 空格输出中文；Shift＋空格输出选中词语译法或已完成的整句英文。
- 每页5个候选，数字1–5选择当前页；↑↓在当前页切换。
- PageUp / PageDown、`-` / `=` 或上一页 / 下一页按钮翻页。
- Tab 展开词语译法与用法；F6切换普通中文 / 中英候选。
- 标点自动跟随确认输出的中英文；设置 → 输入、输入源菜单或 Control＋Shift＋P 可手动切换。
- 已确认选过的词会优先出现，不额外显示记忆标记；个人词库重启后保留。

候选窗：短词横排，中文在上、主要英文在下；点击顶部“译法”选择词语并展开其他译法，或按Tab展开当前词语。长句改用换行列表，整句译文紧随当前候选，超高内容可滚动。设置集中在右上角齿轮，页码和翻页同处顶部。

示例：`shi` 可产生64个候选、13页；`wojintianxiangxuexiyingyu` 可显示“我今天想学习英语”和 `I want to learn English today.`。候选数量随输入变化，桥接层最多返回64项，一次组合输入最多240个拼音字符。

## 开发

当前自动构建面向 Apple Silicon macOS。中文与词语释义的部署目标为macOS 13；Apple本机整句翻译运行需要macOS 26及中英文语言；可选MiniMax模式需要网络和用户配置的API密钥，旧系统实机运行待测。编译需要包含 Translation API 的新 SDK；本机以 Apple Command Line Tools 27验证，其他工具链尚未验证。先安装 Command Line Tools、uv、pnpm；准备脚本将 Rust 1.96.0 与固定上游快照放入忽略的本地目录。

```sh
git clone https://github.com/jizw0704-source/lingomate.git
cd lingomate
bash tools/setup.sh
bash native-macos/tools/build.sh
bash native-macos/tools/check.sh
native-macos/build/BilingualCompanion.app/Contents/MacOS/BilingualCompanion --preview-paging
```

准备脚本不覆盖有改动或提交不符的上游。预览不接收宿主键盘、不安装输入源。安装和试用见原生指南，安装前请了解此实验包的本地签名与系统授权要求。

网页原型采用 TypeScript / Vite、Python 本地服务和共享 Rust 桥接器；只显示前5项及词语释义，整句翻译与分页本次接入原生版。

```sh
pnpm --dir prototype build
pnpm --dir prototype serve
```

访问 http://127.0.0.1:9037 。[网页开发及回归命令](prototype/AGENTS.md)

## 登录与学习记录

候选窗点“设置” → 账号与学习，或输入源菜单 → 设置。原“登录与学习记录”快捷入口仍可使用。未登录不影响输入法使用。

采用自建账号服务，首版邮箱验证码；手机号需以后接短信通道。登录并成功选用词表英文后，记录对应词语和选用次数；可搜索、筛选待掌握/已掌握、手动标记或撤销掌握。断网操作留在当前账号队列，联网可重试同步。仅选择中文、原样拼音、取消或整句翻译不会产生英文单词记录。

**真实在线登录目前还不能使用**：你决定先准备部署说明，尚无服务器、域名或邮件服务。没有用本地昵称冒充真实账号。客户端会显示“账号服务尚未连接”；服务代码、协议和隔离检查已完成，实际邮件、钥匙串、跨设备同步待部署验收。[自建服务部署说明](backend/README.md)。

## 架构与数据

`native-macos/`：Swift / AppKit / InputMethodKit 壳、候选分页、本机整句翻译与语言准备窗口。

`prototype/bridge/`：Rust 候选与译法适配器，验证候选与词语译法，保留剩余拼音。生成的整句英文来自本地系统任务，用已验证中文候选消耗拼音后提交，不允许客户端任意英文绕过词表校验。

`backend/`：Python标准库、SQLite和安全SMTP的自建账号服务，无新增生产依赖。

`prototype/data/`：30个词语及人工编写的多译法用法示例。`tools/`：固定上游准备、离线研究与项目笔记同步脚本。上游、运行时、模型、构建产物与个人安装记录不提交到仓库。

本机选词记忆保存已确认的中文词、拼音、使用次数及最近选择顺序，不保存逐次输入过程，不读剪贴板或宿主上下文，默认不接入云端翻译接口。用户主动启用MiniMax后，只将当前较长中文候选发给配置的接口，不发拼音、正文历史或个人词库。登录后的独立学习账号可向用户配置的自建服务同步所选词表英文、对应中文、词性、使用次数及手动掌握状态；不上传整句、拼音、个人词库或正文。首次系统语言下载需要联网；Apple 框架自身的非文本统计行为见其文档和原生指南。

## 英文译文从哪里来

- **词语查表**：随包离线英文释义表，当前固定快照含232,213个不重复中文条目；30个常见词另有本项目的多译法和用法示例。上游英文表由离线大模型生成，不是逐条审校的专业词典。
- **本机翻译**：没有词表释义的较长当前候选，用 Apple Translation 已下载的中文/英文语言模型生成译文。默认打字时不调用在线翻译服务；先选对中文，再判断英文是否符合语境。

- **MiniMax AI 翻译（可选）**：开启后，没有词表释义的较长候选停顿约850毫秒开始请求；译文旁显示AI在线来源。密钥保存在系统钥匙串，不写进Git、设置文件或Obsidian。失败保留中文、支持重试和切回本机。接口及思考内容分离按[MiniMax官方文档](https://platform.minimax.cn/docs/api-reference/text-openai-api)接入；本轮仅验证隔离协议与界面，真实调用、延迟、质量和Keychain授权待用户配置后验收。
