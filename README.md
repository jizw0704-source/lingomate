# 灵果 · LingoMate

灵果是一款将中文拼音输入与英文翻译结合的输入法。用户可在同一候选窗口中选择中文或英文，查看词语的不同译法与用法，并在中文输入过程中直接提交英文字母。

当前 macOS 源码版本为 **0.12.0 / build 22**，面向 Apple Silicon Mac；Windows 源码版本为 **0.1.2 开发版**。两端均提供远程版本检查、可选每日提醒、下载校验、确认安装与旧版恢复。远程更新包尚未公开发布，更新清单保持未发布状态。项目以早期源码预览形式公开，另提供用于交互验证的网页原型。Windows 功能和验证范围见 [Windows 使用说明](native-windows/README.md)。

## 核心功能

- **中英候选**：同时展示中文候选与英文释义，支持展开其他译法、词性和用法示例。
- **整句翻译**：支持 Apple 本机翻译，以及可选的 MiniMax 在线翻译。
- **混合输入**：空格确认中文，回车确认当前英文字母并保留大小写，随后可继续输入中文拼音。
- **英文直输**：单按并松开 Shift，在中文拼音与英文直输之间切换。
- **候选与记忆**：每页显示 5 个候选，支持翻页；已确认的中文词语保存在本机，并参与后续候选排序。
- **标点与外观**：标点可跟随输出语言，或固定为中文、英文；外观提供白色、黑色和跟随系统三个选项。
- **学习记录**：提供邮箱验证码登录、词条记录和掌握状态管理。自建账号服务尚未部署，在线登录与跨设备同步暂不可用。
- **软件更新**：Mac 在输入源菜单或设置中检查，Windows 在候选窗口或通过 Ctrl＋Shift＋U 检查；自动检查默认关闭，安装需确认，旧版本保留供恢复。

## 使用方式

安装后，在 macOS 输入源菜单中选择“灵果”，输入拼音并选择候选。

| 操作 | 功能 |
| --- | --- |
| 空格 / 数字 1–5 | 确认当前页中文候选 |
| Shift＋空格 | 确认当前词语译法或已完成的整句译文 |
| 回车 | 有组合输入时提交原样字母；无组合输入时由当前应用处理 |
| 单按并松开 Shift | 切换中文拼音 / 英文直输 |
| Tab / Shift＋Tab | 展开译法并切换下一种 / 上一种 |
| PageUp / PageDown，`-` / `=` | 候选翻页 |
| ↑ / ↓ | 切换当前页候选 |
| Esc | 收起译法；再次按下取消组合输入 |

混合输入示例：`wo`＋空格 → “我”，`AI`＋回车 → “AI”，`xuexi`＋空格 → “学习”，最终得到“我AI学习”。确认字母的回车仅提交当前组合；换行或发送消息需要由后续无组合输入的回车触发。

短词候选横向排列，中文与主要英文对应显示；较长候选采用换行列表，整句译文位于当前候选下方。候选窗口右上角的设置入口集中管理账号与学习、翻译、输入和外观。

详细操作与安装方法见 [macOS 使用指南](native-macos/README.md)。

## 翻译来源

| 来源 | 适用范围 | 使用条件 |
| --- | --- | --- |
| 离线英文释义表 | 词语候选及多译法 | 随本地构建的应用提供，无需在线请求 |
| Apple Translation | 无离线释义的较长中文候选 | macOS 26 及以上，已下载中英文语言资源 |
| MiniMax API | 无离线释义的较长中文候选 | 用户主动启用，并配置对应接口的密钥与模型 |

当前固定释义表快照包含 232,213 个不重复中文条目，其中 30 个常用词另附本项目编写的详细用法示例。上游释义由离线大模型生成，尚未经过逐条专业审校。

本机翻译默认在停止输入约 350 毫秒后启动；启用 MiniMax 后，在线请求约在停顿 850 毫秒后启动。翻译处理当前选中的中文候选，中文同音字选择及译文是否符合语境仍需人工判断。整句目前仅提供一种译法。

MiniMax 默认关闭，配置与数据范围见 [MiniMax AI 翻译](native-macos/README.md#minimax-ai-翻译)。

## 开发与运行

基础中文输入与词语释义的部署目标为 macOS 13；较早系统的实际运行兼容性尚未验证。Apple 本机整句翻译需要 macOS 26 及以上。编译需要包含 Translation API 的较新 SDK，当前已验证 Apple Command Line Tools 27。

安装 Command Line Tools、uv 和 pnpm 后执行以下命令。准备脚本使用 Rust 1.96.0 与固定上游快照，并保留已有改动。

```sh
git clone https://github.com/jizw0704-source/lingomate.git
cd lingomate
bash tools/setup.sh
bash native-macos/tools/build.sh
bash native-macos/tools/check.sh
native-macos/build/BilingualCompanion.app/Contents/MacOS/BilingualCompanion --preview-paging
```

预览窗口用于检查布局与交互，不安装输入源，也不接收其他应用的键盘输入。系统输入法安装步骤见 [macOS 使用指南](native-macos/README.md#安装与更新)。

网页原型通过本机服务运行：

```sh
pnpm --dir prototype build
pnpm --dir prototype serve
```

访问 <http://127.0.0.1:9037/>。网页原型仅展示前 5 个候选及词语释义；系统输入、候选分页和整句翻译由原生版本提供。详见 [网页原型说明](prototype/README.md)与[开发命令](prototype/AGENTS.md)。

| 目录 | 内容 |
| --- | --- |
| `native-windows/` | Rust Windows TSF 客户端、候选窗口与构建 / 安装脚本 |
| `native-macos/` | Swift、AppKit 与 InputMethodKit 输入法客户端 |
| `prototype/bridge/` | Rust 候选引擎与译法适配器 |
| `prototype/data/` | 词语多译法、语境及用法示例 |
| `backend/` | 基于 Python 标准库、SQLite 与 SMTP 的自建账号服务 |
| `tools/` | 环境准备、离线研究与文档同步工具 |

账号服务的安装与配置见 [服务端说明](backend/README.md)和[部署说明](backend/deploy/README.md)。

## 数据与隐私

个人词库保存在本机，记录已确认的中文词、拼音、使用次数及最近选择顺序。输入法不读取剪贴板或当前应用正文，不保存逐次输入日志。

用户主动启用 MiniMax 时，仅发送当前中文候选与固定翻译指令；API 密钥保存在系统钥匙串。登录学习账号后，仅向配置的自建服务同步所选词表英文、对应中文、词性、次数与手动掌握状态。整句、原始拼音及个人词库不进入学习账号同步范围。

Apple 翻译语言资源首次下载需要联网。系统框架的数据处理说明见 [翻译与隐私](native-macos/README.md#翻译与隐私)。上游快照、运行时、构建产物、凭据及个人使用数据不提交至仓库。
