# Windows 验证记录

2026-10-09 · 首版 0.1.0 开发接入。

## 本机已检查

- Rust Windows x64 GNU 目标类型检查：文本服务 DLL 与共享引擎通过；不包含 Windows 链接或实际注册。
- 2 项输入状态检查与 7 项真实桥接集成检查：中文、英文及第三译法、保留大小写的混合输入、部分提交剩余拼音、当前页选择、基础标点、非法译法拒绝，以及挂起 / 无效 / 过大响应的时限与隔离进程回收。
- 共享引擎新增条件编译：Unix 保留原文件权限与原子替换；Windows 使用 MoveFileExW 原子替换，首版 Windows 文本服务未启用个人词库。
- 输入源码、安装包与个人数据不从 macOS 试用环境迁移至 Windows 测试。现有服务端未提交改动保留。

## Windows 检查流程

已准备 MSVC 编译、PowerShell 语法、Rust 格式 / Clippy、真实引擎集成及 DLL 类厂加载 / 释放测试。首次远端运行结果待确认。检查不注册输入源、不发送按键、不访问邮箱、钥匙串或真实账号。

## 待实际验证

- COM / TSF 登记、权限要求及系统输入切换器中的可见性。
- 记事本、浏览器、微信和钉钉等应用中的中文、英文译法与原样字母提交。
- 连续输入、空回车、组合快捷键、Shift 切换、密码框、输入法及应用焦点切换。
- 候选点击不抢焦点、屏幕边界、DPI、多显示器、主题、高对比与辅助功能。
- DLL 卸载、应用退出、引擎异常恢复，以及安装失败回退 / 卸载。
- Windows 10、ARM、32 位应用与现代应用。

候选窗口采用 Pheno v1.4 的中性配色与无动画原则，普通候选与英文选择区域高度为 44 像素；实际渲染、缩放、鼠标状态、完整文本展示与辅助功能尚未验收。本机为 macOS，不能据跨目标编译宣称 Windows UI 或实体键盘已通过。
