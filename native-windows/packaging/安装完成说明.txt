安装后开始试用

1. 打开“设置 → 时间和语言 → 语言和区域 → 中文（简体）→ 语言选项 → 添加键盘”，找到“灵果”。也可先检查 Win＋空格切换列表。
2. 保存工作后完全退出并重新打开需要试用的应用，再使用 Win＋空格选择灵果。
3. 在空白文稿输入 xuexi，空格选择中文，点击英文候选选择英文。
4. 输入 API 后按回车，应直接输出 API；单按 Shift 切换直接英文输入。
5. 点击候选窗“更新”或按 Ctrl＋Shift＋U，可检查新版本。自动检查默认关闭，启用后只提醒，安装由本人确认。

不会自动关闭应用、切换输入源、结束 ctfmon 或重新启动电脑。
安装后仍无候选、常用软件不兼容或更新失败时，请记录 Windows 版本、应用名称及可重复操作步骤，联系项目维护者；不要发送聊天正文或个人词库。
