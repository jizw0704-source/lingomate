安装后开始试用

1. 打开“设置 → 时间和语言 → 语言和区域 → 中文（简体）→ 语言选项 → 添加键盘”，找到“灵果”。也可先检查 Win＋空格切换列表。
2. 保存工作后完全退出并重新打开需要试用的应用，再使用 Win＋空格选择灵果。
3. 在空白文稿输入 xuexi，空格选择中文，点击英文候选选择英文。
4. 输入 API 后按回车，应直接输出 API；单按 Shift 切换直接英文输入。
5. 点击候选齿轮或按 Ctrl＋逗号，打开账号／翻译／输入／外观／学习设置；F6 切换普通中文／双语候选，Ctrl＋Shift＋P 循环标点规则。
6. 在“翻译”页配置 API 地址、模型和密钥，点击“保存并启用 AI”后确认“已保存 · ••••••••”。点击“测试连接”会用固定示例“今天下午开会。”验证认证及模型调用，会使用少量额度，测试不保存或启用 AI；保存本身不会发请求。输入 jintianxiawukaihui，译文就绪后用 Shift＋空格确认；API 首次默认关闭。
7. 从“外观”页检查版本更新，或按 Ctrl＋Shift＋U。自动检查默认关闭，启用后只提醒，安装由本人确认。

不会自动关闭应用、切换输入源、结束 ctfmon 或重新启动电脑。
安装后仍无候选、常用软件不兼容或更新失败时，请记录 Windows 版本、应用名称及可重复操作步骤，联系项目维护者；不要发送聊天正文或个人词库。
