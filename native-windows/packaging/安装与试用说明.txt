灵果 LingoMate · Windows 开发测试版

设备要求：Windows 11，Intel / AMD 64 位电脑。暂不支持 Windows ARM 或 32 位应用中的原生输入服务。

运行文件安装到当前用户目录；登记灵果自己的 Windows 输入服务时，需要同一账号的管理员确认（UAC）。请使用原登录账号完成确认，避免改用其他管理员账号。安装前先保存输入内容并切换到其他输入法。
安装会验证完整文件清单；旧版本保留在用户的 LocalAppData\LingoMate\Windows，个人数据不会被删除。

当前 Windows 版提供中文拼音、中英候选、翻译展开、候选翻页、Shift 直接英文输入、回车输出原始字母及版本更新。
Windows 另提供本机中文选词记忆、本地单词学习、外观／字号与标点设置。Mac 的账号同步、AI 整句翻译及独立设置窗口尚未完整移植，不能视为两端完全一致。

卸载仅移除灵果自己的输入源／类登记和安装器支持文件，保留历史版本及个人数据。
本开发包尚未完成 Windows 11 实机输入、升级和回退验收，也未使用发行签名。完整词库分发确认完成前不公开发布。
公司电脑可能有应用安装策略；遇到限制请联系公司 IT，不修改公司安全策略。
