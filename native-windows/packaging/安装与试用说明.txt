灵果 LingoMate · Windows 开发测试版

设备要求：Windows 11，Intel / AMD 64 位电脑。暂不支持 Windows ARM 或 32 位应用中的原生输入服务。

运行文件安装到当前用户目录；登记灵果自己的 Windows 输入服务时，需要同一账号的管理员确认（UAC）。请使用原登录账号完成确认，避免改用其他管理员账号。安装前先保存输入内容并切换到其他输入法。
安装会验证完整文件清单；旧版本保留在用户的 LocalAppData\LingoMate\Windows，个人数据不会被删除。

当前 Windows 版提供中文拼音、中英候选、多译法、候选翻页、Shift 直接英文输入、回车输出原始字母、本机选词与逐字组词记忆、本地单词学习及版本更新。
0.1.21 修复候选整句翻译队列繁忙时停止请求并误报“本机翻译尚未准备好”的路径，改为等待重试；辅助进程不可用时单独提示。包含下述0.1.20的密钥状态及独立连接测试改进。
0.1.20 在 API 密钥框下显示“已保存 · ••••••••”，输入新密钥时显示待保存，保存失败保留输入。新增独立“测试连接”按钮，显示成功耗时或失败原因；只发送固定示例句，会使用少量额度，测试不会保存或启用 AI。已有配置与本机凭据保留。
0.1.19 修复设置页滚动和切页时旧文字残留、输入框遮挡的问题，并更名“本机翻译设置”入口。
0.1.17 增加账号／翻译／输入／外观／学习五页设置，F6 切换普通中文／双语候选，Ctrl＋Shift＋P 循环标点规则。
在线 AI 翻译默认关闭。用户配置并开启后，只向指定接口发送当前中文候选，不上传拼音、输入历史或个人词库；保存 API 设置不发请求，密钥保存在本机凭据管理器。账号仅同步所选词条元数据，不同步整句。
本机整句翻译需要另行准备已安装模型且关闭云功能的 Ollama。账号邮件服务需要配置自建 HTTPS 服务。MiniMax 国内接口已完成真实配置及单次授权／响应检查；实际候选触发、取消与提交，以及账号／本机模型服务仍待用户试用验收。

卸载仅移除灵果自己的输入源／类登记和安装器支持文件，保留历史版本及个人数据。
本开发包尚未完成 Windows 11 实机输入、升级和回退验收，也未使用发行签名。完整词库分发确认完成前不公开发布。
公司电脑可能有应用安装策略；遇到限制请联系公司 IT，不修改公司安全策略。
