# Windows 更新与发布

自 Windows 0.1.1 开发版提供，面向 Windows 11、Intel / AMD 64 位电脑。macOS 尚未接入远程更新。

首次安装可构建独立安装 EXE，后续更新继续使用 ZIP 更新包；两者共享校验与版本目录逻辑。安装包制作见 [安装包与同事试用](../docs/PACKAGING.md)。目前未发布安装 EXE 或更新 ZIP。

## 用户操作

点击候选窗“更新”或按 Ctrl＋Shift＋U，依次执行检查更新、查看说明、下载校验、确认安装。安装后，保存工作并切换到其他输入法，重新打开对应应用，再选择灵果。已经打开的应用可能继续使用旧 DLL，磁盘版本变化不代表所有应用已加载新版本。

每日自动检查默认关闭，启用后在输入法激活时检查间隔，至多每 24 小时自动检查一次，仅有新版本时显示窗口。采用用户级互斥，避免多个应用重复弹出。手动检查不受间隔限制，设置只记录检查选项与时间，不记录输入内容。

下载可取消；安装或恢复登记开始后不可中途取消。网络请求在独立进程中进行，取消只终止本次更新进程，不终止宿主应用或输入法。

## 安装与回退

新版本保存至 `%LOCALAPPDATA%\LingoMate\Windows\` 下以“版本号＋清单摘要”命名的目录。先复制至临时目录并重新校验，再转换为版本目录并登记。旧版文件保留，安装记录保存原 DLL 路径；重复安装同一版本不覆盖原文件。

校验失败不会登记新版本。登记失败尝试恢复原登记；恢复也失败时明确报告，不宣称已回退。“恢复上一版本”会先验证旧版清单，拒绝本项目目录之外的路径。回退后也需重新打开应用。

## 发布约定

- 来源固定为 `jizw0704-source/lingomate`，不读取自定义更新地址或账号令牌。
- 标签：`windows-v<主版本>.<次版本>.<修订号>`，例如 `windows-v0.1.1`。
- 更新清单位于 `updates/windows-preview.json`，通过固定 raw.githubusercontent.com 地址读取，不使用受公共 API 配额限制的发布列表。清单为 Windows `preview` 通道，拒绝其他平台、相同及低版本。
- 附件：`lingomate-windows-update.json` 和 `lingomate-windows-x64-<版本>.zip`。
- 元数据含平台、架构、通道、版本、最低 Windows 构建号、包名称、大小、压缩包与文件清单 SHA-256。
- 仅接受本仓库 HTTPS 发布链接及明确允许的 GitHub 附件 CDN 重定向；不关闭证书验证。

下载检查大小、摘要、文件清单及平台版本，拒绝额外文件、重复名称、路径跳转、链接和超大文件。信任边界为本项目 GitHub 发布账号；HTTPS 与 SHA-256 不等同于独立发行签名。更新不上传输入内容、个人词库、学习记录或账号信息。

## 准备发布

Windows 构建机器执行：

```powershell
./native-windows/tools/setup.ps1
./native-windows/tools/build.ps1
./native-windows/tools/check.ps1
./native-windows/tools/prepare-release.ps1
```

脚本仅生成本地 `native-windows/package/release-<版本>/`，不上传发布。调整 Cargo.toml 和 Cargo.lock 的版本后须重新构建、检查。实机安装 / 输入 / 更新 / 回退、数据分发许可和发行签名安排完成后，再将两个附件放在同一版本标签的 GitHub Release，并添加更新说明。可先建立草稿复核。公开发布并验证附件可下载后，将生成的元数据复制至 `updates/windows-preview.json` 并提交同步；在此之前保持清单为 unpublished，避免向同事推送不可下载的草稿。

**推送源码或通过构建不会触发更新，必须发布对应附件并更新清单。** 当前清单为 unpublished，尚未发布 Windows 更新包，客户端将显示没有更高版本可用。自动检查只保存隔离生成的更新窗口截图，不上传词库或安装包。

## 验证范围

回归使用临时目录与合成文件，模拟登记与回退，不访问真实安装，不登记系统输入法。分别使用 Windows PowerShell 5.1 和 PowerShell 7。UI 检查覆盖忙碌、取消、重试及登记时禁止中断，并生成 Windows 原生窗口截图。

真实发布下载、更新登记、跨应用重新加载、每日提醒、公司代理和运行策略、DPI、高对比与屏幕阅读器仍需实机验证。详见 [Windows 验证记录](QA.md)。
