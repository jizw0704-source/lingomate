## 3. 隐私、服务与平台差异

在线AI首次关闭。预设只填字段，保存配置不发送测试请求；开启后仅发送精确当前中文候选与固定指令。原始拼音、宿主正文、选区、剪贴板、个人词库文件和输入历史都不发送或采集。输入、候选、页码、上下文、配置、取消与提交使对应旧请求／结果失效。未完成或不符合响应合同的英文不能提交。

凭据仅在独立无包身份helper访问Windows凭据管理器，按完整地址或账号会话隔离，不写普通配置、参数或日志。包内调用经relay进入已验证的无包身份进程；失败时显示未完成，不在包私有视图里继续保存并宣称成功。HTTP使用WinHTTP，不在键盘回调等待网络。

账号同步只携带所选词表英文、对应中文、词性、累计选用和掌握相关元数据，不含整句、原始拼音、宿主正文或中文个人词库。本地学习不以登录为前置，也不自动迁移到账号。真实邮件和在线同步需要单独部署与验收；客户端实现不等于服务上线。

本机模型路径只接受 `127.0.0.1`／`::1`。还必须从 `/api/status` 验证 `cloud.disabled=true`，并核对已安装模型的digest、大小和本地身份；仅有回环地址不足以证明不会云端推理。模型不符合条件时拒绝本机请求，不静默切到云模型。本轮不下载模型，不替用户开启Ollama；真实本机能力仍待验收。“验证并准备”会用固定测试句访问本机服务，与API保存不请求是两条路径。

Mac的Apple语言准备界面、Keychain、签名／公证和系统输入源菜单由Windows对应方案替代；功能和状态目标相同，平台实现与条件分别记录。双方完整读屏、高对比、长期稳定性、公开账号和远程更新验收仍有待补项。短信登录、整句多译法、全词库完整例句或宿主上下文AI纠错不作为现有Mac能力冒领。

## 4. 设置和个人数据

中文记忆新位置为 `%USERPROFILE%\.lingomate\PersonalVocabulary\words.json`，避开MSIX对AppData的重定向。无包身份helper仅在新文件不存在时，从真实 `%LOCALAPPDATA%\LingoMate\PersonalVocabulary\words.json` 校验并复制一次；旧文件保留，已有新数据不覆盖。损坏或超限源文件报告错误，旧MSIX私有历史不自动合并。实际迁移需要另记录版本、备份、冲突和恢复，不能只看新文件存在。

英文本地学习继续使用真实 `%LOCALAPPDATA%\LingoMate\LocalWords\words.json`；账号缓存和翻译公开配置由无包身份helper在真实 `%LOCALAPPDATA%\LingoMate` 下分别保存。翻译配置不含密钥。个人中文词库、英文学习和账号记录相互独立，CSV导出仍限学习词条。

外观、候选字号和词性持久保存；语言、候选模式、标点及记忆写入的运行期状态通过同用户设置通道协调。对齐Mac时要核对Windows多宿主与服务运行期的映射，不能把所有选项统一永久保存。显示设置只重绘；其他输入设置和主动打开设置按组合结束规则处理。服务未确认时不显示假成功。
