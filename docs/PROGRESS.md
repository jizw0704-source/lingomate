# 灵果 · 开发进展

更新日期：2026-10-09。当前原生版本：**0.11.8 / build 20**。

## Windows 并行开发

新增 Windows 0.1.0 开发客户端：原生 TSF 文本服务、非激活候选窗口、共享引擎、中英词语选择、多译法、候选分页、原样大小写提交、Shift 切换及基础标点。准备固定源码构建、校验清单、版本隔离安装、登记回退与卸载脚本，并加入 Windows 自动检查流程。

Windows 目标类型检查及 2 项输入状态 / 7 项真实引擎检查已通过；远端 Windows MSVC 构建及 DLL 加载结果待确认。实际系统登记、应用输入、视觉、DPI、辅助功能与稳定性待 Windows 机器验收。账号、MiniMax、完整标点、个人词库、外观及系统图标尚未移植；未改动当前 macOS 安装版。[Windows 使用说明](../native-windows/README.md) · [Windows 验证记录](../native-windows/QA.md)。

## 已确认的实际试用

- 0.11.7 的基本混合输入已获实体键盘确认：输出“我AI学习”时无需切换中英文模式。具体应用未提供，空回车行为及长期跨应用流程仍待逐项验证。
- 系统输入源菜单已确认显示“灵果”，`CFBundleName` 占位项已消失。此前安装包与登记信息更新后，菜单仍缓存旧名称；经授权刷新输入菜单进程后显示更新。详细操作与原始反馈保存在安装记录中。
- Codex、微信和钉钉分别重新打开后，已收到输入恢复反馈。该结果确认当次恢复，尚不能确定故障根因或证明长期稳定性。

原始测试结果、用户反馈及安装过程见 [验证记录](../native-macos/QA.md)与[安装登记与重载记录](../native-macos/INSTALLATION.md)。历史记录中的待确认状态，应结合后续反馈及本文当前状态阅读。

## 验证范围

原生版本已完成 Swift 格式、类型与构建检查，Rust 格式与 Clippy 检查，以及资源、属性和本地签名核验。真实引擎回归覆盖候选分页、中文与英文提交、非法译法拒绝；隔离选词记忆测试覆盖重启保留、单次确认、组词、防误记、文件损坏及保存失败。

输入状态检查覆盖单按 Shift、组合键保护、焦点边界、标点映射、语言状态与剩余拼音。引擎故障恢复检查覆盖异常退出、超时、旧提交与旧回执，以及 3,000 次查询。安装流程已通过 5 项隔离检查。

候选预览已检查横向短词、长句换行、窄幅深色布局、展开译法、后页选择与末页禁用。网页原型已完成文本与本机 HTTP 回归。预览和自动检查仅覆盖对应路径，实际应用接入以实体键盘反馈为准。
