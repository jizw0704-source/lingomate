# 中英输入法 · 开发进展

更新：2026-10-08。当前原生版本0.9.0。

## 已实现

- 词语中英文独立选择、词语多译法展开及示例用法；普通中文 / 中英候选随时切换。
- 0.2：Apple 本机整句翻译，语言准备、加载、失败重试；输入上限240个拼音字符；组合输入变化会取消旧译文。
- 0.3：每页5个候选、当前页数字选择、PageUp/PageDown、减号/等号及按钮翻页；共64项上限。翻页选中首项，清除旧展开与整句译文；第一页、末页不能继续越界。
- 0.4：本地确认选词记忆、次数/最近选择排序、重启保留、同一组合输入分次选字合成新词；标记“记忆”，本次暂停新增学习。取消、原样拼音和未确认提交不学习，英文学习对应中文但不参与新词拼接。
- 0.5：标点跟随确认输出语言，固定中/英文覆盖、候选窗/菜单及Control＋Shift＋P切换；中文引号、括号、数字及常见地址保护，拼音分音符和分页保留。自动标点前先提交中文候选，部分候选保留剩余拼音。
- 0.6：单按释放Shift切换中文拼音 / 英文直输；字母/数字/标点直接交还原应用，组合Shift不误切换。菜单、候选按钮和短暂模式提示可切换；剩余拼音原样保留，中文功能和设置继续可用。
- 保留网页实验原型、固定上游和可复现开发脚本。
- 0.7：Pheno v1.4原生界面整理，拼音/模式分层、中英列对齐、更多译法及整句译文紧随当前候选；长中文完整换行、窄面板上下排列、固定圆角边框与顶部起始滚动。空候选提示、按钮悬停/按下/禁用、页码、英文直输与语言准备窗口统一。

- 0.8：白色 / 黑色 / 跟随系统，候选窗与输入源菜单入口；本机只保存本应用外观选择，候选、模式提示及翻译准备窗口统一。动态颜色更新现存视图，保留拼音、页码、展开与翻译状态；预览和自测隔离实际偏好。

- 0.9：紧凑候选窗、学习入口和独立账号页。按用户选择采用自建邮箱验证码服务，手机号待接短信。登录后记录确认选用的英文词条、次数及手动掌握状态；搜索、筛选、撤销掌握、按账号隔离、离线队列和幂等同步。新增Python标准库SQLite/SMTP服务及部署说明，没有新增生产依赖。
- 用户当前没有部署资源，决定先准备说明。尚未公开部署、发送真实邮件、验收真实Keychain或跨设备同步；应用显示未连接，不假登录。[部署说明](../backend/README.md)。
- 译词来自232,213个不重复中文条目的随包离线生成释义表、30个本项目详细词例；没有释义的较长候选来自Apple本机模型。学习功能不声称这些译词已专业审校。

## 已检查

新增Shift状态机检查涵盖左右Shift、组合、长按、双Shift、鼠标/焦点和CapsLock状态，并用隔离真实引擎检查取消及中文恢复。新增标点规则及真实引擎提交检查涵盖中英文映射、手动覆盖、引号、数字/地址、分音符、上下文重置及部分提交剩余拼音。Swift格式、类型、构建、原生状态及签名；Rust格式、Clippy和桥接构建；8项真实引擎测试含后页中文/英文提交与伪造译法拒绝。新增10项隔离真实桥接记忆测试涵盖进程重启、单次确认、防误记、组新词、英文、缩写/分音符、损坏保留及保存失败。分页状态覆盖0、1、5、6、9、12、64项、当前页数字映射、末页空位、边界和输入重置。

原生预览中实际点击了第二页的 `city`、第13页的“豕”，首末页按钮禁用状态正确。三个真实本机翻译与引擎消耗联调通过。网页有3项文本回归和4项HTTP回归；完整检查证据见 [QA](../native-macos/QA.md)。
